# GitHub + Final Submission Guide

## 1. Create the repository (once)

1. Go to https://github.com/new, name it e.g. `cv-cca3-image-processing`, choose **Private** (or Public), do NOT add README/.gitignore (we already have them), click *Create*.
2. In the VS Code terminal (inside the project folder):

```
git init
git branch -M main
git add .
git commit -m "CCA 3: complete computer vision project"
git remote add origin https://github.com/<your-username>/cv-cca3-image-processing.git
git push -u origin main
```

If git asks who you are:
```
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```
GitHub asks you to log in in the browser the first time you push (or use a Personal Access Token as the password).

Run `python main.py` BEFORE the commit so `outputs/` (images, tables) is included. Videos are ignored by
`.gitignore` on purpose (assignment: large videos go to Google Drive).
